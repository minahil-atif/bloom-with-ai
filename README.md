🌸 Bloom with AI

Discover AI. Explore Possibilities. Create More.

📌 Project Overview

Bloom with AI is an AI tools directory website designed to help users discover useful AI tools across different categories. The project aims to make exploring artificial intelligence easier and more accessible.

🎯 Project Objectives

- Introduce users to different AI tools.
- Organize AI tools into accessible categories.
- Help users explore creative and productive uses of AI.
- Create a simple and engaging user experience.

✨ Key Features

- AI tools directory
- Categorized tool discovery
- User-friendly website interface
- Informative tool descriptions
- Easy navigation

🛠️ AI Tool Used

AI website builder: Lovable

💬 Prompt Used

:
Build a complete, modern, beautiful, and genuinely useful AI tools discovery website called AI Bloom.
Tagline: “Discover. Create. Bloom with AI.”
1. Website Purpose
Create one central platform where students, teachers, professionals, content creators, and beginners can discover useful AI tools without searching dozens of different websites. Help users find the right tool for their task,
understand how it works, compare alternatives, and visit its official website.
2. Design and Theme- Use a premium lavender, pastel pink, lilac, and white aesthetic.- Add subtle gradients, elegant typography, rounded cards, soft shadows, delicate animations, and attractive icons.- Create a clean, professional, visually distinctive interface.- Make the website responsive and accessible on mobile, tablet, and laptop.- Avoid overcrowded layouts and excessive decoration.- Use consistent spacing, readable text, and clear navigation.
3. Homepage
Create a beautiful landing page featuring:- AI Bloom logo and navigation bar.- Headline: “Find the Perfect AI Tool for Anything.”- Subtitle: “Discover smarter ways to learn, create, and work — all in one place.”- A prominent, fully functional search bar with suggestions.- A “Find My AI Tool” interactive button.- Popular AI tools and featured categories.- Free and beginner-friendly tool sections.- A “New to AI?” beginner guide.- A “Compare Tools” shortcut.- A footer with About, Contact, Suggest a Tool, and Privacy information.
4. AI Tool Categories
Organize real AI tools into these categories:
1. AI Chatbots and Assistants
2. AI Writing and Grammar
3. AI Image Generation
4. AI Video Generation and Editing
5. AI Presentation Makers
6. AI Website Builders
7. AI Coding Assistants
8. AI Study and Education
9. AI Research and Summarization
10. AI Voice, Music, and Audio
11. AI Translation and Language Learning
12. AI Design and Logo Creation
13. AI Productivity and Planning
14. AI Business and Marketing
Every category must be clickable and display relevant tools.
5. AI Tool Cards
Each card should display:- Tool name and logo or appropriate icon.- Short, easy-to-understand description.- Main category.- Best use case.- Pricing status: Free, Freemium, Free Trial, Paid, or Unverified.- Beginner-friendly label when appropriate.- “Learn More” button.- “Visit Official Website” button.
All external links must lead to the correct official tool websites. Do not invent tool names, logos, features, ratings, prices, or links.
6. Smart Search and Filters
Implement a fully working search feature that searches tool names, descriptions, categories, and use cases.
Include filters for:- Category.- Free tools and tools with free plans.- Paid tools and free trials.- Beginner-friendly tools.- Alphabetical order and recently added tools.
Show a helpful message when no matching tools are found.
7. Unique Feature: Find My AI Tool
Create an interactive recommendation wizard.
Ask users: “What do you want to do today?”
Offer tasks such as:- Generate an image.- Create a video.- Make a presentation.- Improve English.- Write or summarize text.- Study for exams.- Build a website.- Write or debug code.- Research a topic.- Generate voice or music.- Translate languages.- Create a logo or design.
Ask about their budget: Free only, Free plan available, or Any budget.
Display matching tools with explanations of why they suit the selected task. Implement this initially using a functional task-to-category recommendation system and the website's tool dataset. Do not falsely claim live AI
recommendations.
8. Unique Feature: Tool Comparison
Allow users to select up to three tools and compare them side by side based on:- Purpose and best use case.
- Pricing category.- Beginner friendliness.- Main features.- Important limitations.- Official website links.
Use verified information only. Clearly mark unknown information as “Not verified.”
9. Unique Feature: Student Mode
Create a dedicated student-friendly section with tools for:- Understanding difficult topics.- Preparing presentations.- Improving English and grammar.- Summarizing study materials.- Generating practice questions.- Organizing assignments.- Creating educational images and diagrams.- Researching academic topics.
Include a task selector that recommends suitable tools for each student need. Encourage students to understand and verify AI-generated work rather than blindly submitting it.
10. Unique Feature: Free Tool Finder
Build a dedicated page for discovering affordable AI tools.
Distinguish clearly between:- Completely free tools, when verified.- Tools with free plans.- Tools offering free trials.- Paid tools.- Tools with unverified pricing.
Never describe a tool as completely free merely because it has a limited free trial.
11. Unique Feature: Beginner Mode
For every tool, provide a simple guide explaining:- What the tool does.- Who can use it.- What users can create with it.- Howto get started.- Whether an account is required, when verified.- Pricing information and limitations.
Use simple English with optional Roman Urdu explanations to make the website accessible to Pakistani students and other beginners.
12. Unique Feature: Prompt Playground
Create a searchable library of reusable AI prompts for:- Image generation.- Video creation.- Presentations.- Writing and summarization.- Studying and learning.- Coding and website building.- Creative ideas and productivity.
Let users browse prompts by category, open and edit them, and copy them with one click. Explain which type of AI tool works best with each prompt.
13. Unique Feature: Favorites and Personal Collection
Allow users to save favorite tools and prompts, remove saved items, and revisit them later.
Use browser-local storage for the initial version so saved items persist after refreshing the page. Explain that locally stored data may not sync across devices and can be lost if browser data is cleared. Do not add fake login or
fake cloud synchronization.
14. Real and Trustworthy Tool Directory
Start with a useful collection of real, well-known AI tools across multiple categories.
Use a structured, maintainable dataset containing each tool's name, description, category, use cases, pricing status, beginner guidance, and official URL.
Use reliable information and clearly identify details that have not been verified. Make it easy to add more tools later.
Do not claim the directory contains every AI tool or displays live popularity, ratings, or pricing unless those capabilities are genuinely implemented.
15. Suggest a Tool
Add a working form where visitors can suggest a new AI tool by entering its name, official URL, category, and a short description.
Validate the input and display a clear confirmation. If no backend is configured, store suggestions locally or explain that the submission is only saved in the current browser. Do not pretend suggestions have been sent to an
administrator.
16. About and Privacy
Add an About page explaining the purpose of AI Bloom and how it helps users discover AI tools.
State clearly that AI Bloom is an independent directory and is not affiliated with the listed companies.
Provide a simple privacy notice explaining how favorites and other locally stored information are handled.
17. Technical and Functional Requirements- First inspect my existing Lovable project and preserve useful work.- Build the actual working website, not just a static mockup.- Make search, filters, category navigation, recommendations, comparison, favorites, and prompt copying functional.- Ensure all buttons, menus, forms, and external links work correctly.- Add loading states, empty states, validation, and helpful error messages where appropriate.- Use reusable components and a clean, maintainable project structure.- Use appropriate accessibility practices.- Do not require paid APIs for the initial version.- Do not add a fake AI chatbot, fake live search, fake user accounts, or nonfunctional features.- Do not expose API keys or secret credentials in frontend code.- Test the important features and fix errors before completion.
Final Goal
Deliver a polished, interactive, beginner-friendly AI tools discovery platform with a distinctive lavender-pink identity and genuinely useful features. Prioritize accurate information, working functionality, ease of use, and practical
value over excessive decoration.The website should be suitable for a university IT assignment and should have room to grow into a larger public project in the future.https://bloomwithai.lovable.app
